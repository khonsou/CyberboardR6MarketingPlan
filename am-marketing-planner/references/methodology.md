# AM 策划方法论

> 制定策略与提案时按此框架执行。带 ⏳ 的小节待用户补充确认。
> 主框架来源：品牌资料/营销方法论-纳瓦尔奥格威.txt（六大师全维度模型）。

## 策划主框架：六大师全维度模型（The Master Brand Architect）

任何策划任务按以下六步推导，每步用对应大师的透镜审视、批判、优化。

### 金字塔模型（心智定位图）

```
塔尖  灵魂/哲学    纳瓦尔 Naval      第一性原理：解决了什么根本问题？是否用上了独有专长？
塔身  骨架/产品    霍尔莫兹 Hormozi  价值方程式：梦想结果够大吗？用户的痛苦和等待够小吗？
塔皮  皮肤/差异化  高汀 Godin        这是一头紫牛吗？值得被讨论吗？部落是谁？
塔口  嘴巴/表达    奥格威 + 汉德利    标题够狠吗？故事够真吗？文案有销售力吗？
塔基  双脚/增长    帕特尔 Patel      关键词对吗？SEO 做了吗？数据反馈如何优化？
```

### 六步推导流程

**Step 1 纳瓦尔的灵魂拷问（The Foundation）**
- 这个方案的第一性原理是什么？解决了什么本质需求？
- 是否用上了 AM 的"特定知识"（客制化工艺、社区共创、亚文化理解——别人复制不了的）？
- 是否存在"代码或媒体"的零边际成本杠杆（UGC、社区内容、工具型资产如 keymatrix.dev）？

**Step 2 霍尔莫兹的价值整形（The Offer）**
- 价值方程式评分：价值 = (梦想结果 × 感知达成可能性) / (时间延迟 × 努力与牺牲)
  - 梦想结果 [0-10] / 感知可能性 [0-10] / 时间延迟 [0-10，越低越好] / 努力与牺牲 [0-10，越低越好]
- 给出 3 个具体策略让分子变大、分母变小（赠品、保障、交付方式——对 AM 例如：抽签保障、免费外观修复、48h 发货、众测折扣）
- 警戒线：Offer 不够强时，营销再好也是诈骗——先整形 Offer 再做传播

**Step 3 赛斯·高汀的紫牛测试（The Positioning）**
- 这个方案"卓越到值得被讨论"（Remarkable）吗？如果不是，如何让它变异？
- 最小可行受众（Minimum Viable Audience）是谁？——对 AM 通常对应 audience.md 四类画像中的某一圈层，越窄越好
- "安全就是冒险"：同质化的稳妥方案 = 最大风险（与 AM 反 ME-TOO 基因一致）

**Step 4 奥格威 × 汉德利的创意工坊（The Message）**
- 奥格威透镜：基于事实与研究的文案；标题决定 5 倍阅读量——输出 3 个强销售力、基于利益点的标题
- 汉德利透镜：企业说话要像人——输出一段温暖、以"你"为中心、拒绝八股的品牌叙事
- 统一法则：**用汉德利的语气，执行奥格威的销售目的**

**Step 5 尼尔·帕特尔的增长引擎（The Growth）**
- SEO 与关键词：指出 3 个高潜力、低竞争的长尾关键词（海外参照 CYBERBOARD 作为独立站流量引擎的模式）
- 分发策略：基于数据逻辑选定主渠道（独立站 SEO / YouTube / 邮件 / 社媒），说明为什么
- A/B 测试与转化漏斗：给出可量化的优化假设

**Step 6 最终执行摘要**
- 汇总六步结论，输出精炼的"品牌行动指南"（一页可读完）

### 大师辩证速查（方案内部冲突时）

| 冲突 | 双方 | 统一解法 |
|------|------|----------|
| 硬销售 vs 软故事 | 奥格威 vs 汉德利 | Big Idea 往往就是核心故事；用人味语气完成销售目的 |
| 艺术 vs 科学 | 高汀 vs 帕特尔 | 用高汀做定位，用帕特尔做执行放量；缺前者推的是垃圾，缺后者紫牛没人看见 |
| 道 vs 术 | 纳瓦尔 vs 霍尔莫兹 | 纳瓦尔定战略方向（做正确的事），霍尔莫兹给战术武器（把吸引力做到极致） |

### 阶段使用指南（按任务阶段选择主透镜）

- 产品/Offer 打磨期 → 盯霍尔莫兹：用户能否"不费吹灰之力"得到结果？
- 市场切入期 → 盯高汀 + 帕特尔：高汀定切哪个人群（越窄越好），帕特尔定去哪里找他们
- 内容输出期 → 盯奥格威 + 汉德利：标题要像奥格威一样狠，内容要像汉德利一样真
- 方向迷茫期 → 回到纳瓦尔：这是否符合 AM 的第一性原理与长期主义？

## AM 已验证的打法工具箱（优先复用，再谈创新）

### 1. 限量预购发售（核心机制）
公告 → 限时限量预购（数小时/数天）→ 分钟级售罄 → 二级市场发酵
- 关键动作：社群首发公告、稀缺性叙事（"永不复刻"）、发售倒计时
- 风险：黄牛干扰、抢不到的用户流失——方案中可设计白名单/抽签/社区专属批次对冲

### 2. 众测模式（上市前口碑引擎）
招募 → 提前体验 → 按要求分享内容
- 激励：参与奖=众测机 9 折购买资格；优质内容奖=更多折扣或免费机器
- 收益：真实反馈（提前发现工艺/调教问题）+ 大量高质量 UGC 资产 + 低营销成本
- 阵地：微信群 + ZFrontier

### 3. The Novel Project 共创（品牌级 IP 机制）
开放多彩阳极工艺 + 白模渲染图 → 全球用户/品牌/IP 方投稿 → 中选者与 inhouse 设计师联合完成 → 限量发售、永不复刻
- 已发布：Novel-01 金佩斯利 / 02 月之暗面 / 03 亢奋 / 04 西游
- 价值：设计成本外部化 + 忠诚度深度绑定；"从用户到品牌"的逆向创新

### 4. 隐藏款 / 抽奖盲盒
- 案例：RGB 65 8-Bit Edition 仅 7 台，不售卖、抽奖分发，手工喷漆 + 30 天免费外观修复
- 要点：坦诚工艺局限反而增强故事性；隐藏款是话题放大器而非销量工具

### 5. 社群日常运营
- ZFrontier 装备签到（每日）、抽签活动（如 Carpio G2.0 抽奖）、开箱分享（B 站）
- 社区自组织信号（用户自发开发 keymatrix.dev）值得官方放大与致敬

### 6. 海外传播
- 以"全球首创"事实点争取媒体报道（参照 AM HATSU 案例）
- KOL 方向：打字音博主、ASMR 创作者、桌搭美学博主
- 阵地：Discord / Twitter / Reddit / 独立站 SEO（CYBERBOARD 为流量引擎关键词）

### 7. 海外 KS 30 天发布节奏（AM 鼠标发布验证，众筹先行模式通用）
> 来源：品牌资料/AM鼠标-30天海外KS发布节奏.md。**D Day = KS 正式 launch / 海外完整详情页发布日**，倒排与正排都以此为锚。

**合规底线**：诚实透明、以工作原型/开发进展为素材核心；KS 明确禁止 photorealistic renderings（渲染图不能充当产品实拍）。

**节奏总逻辑**：理解（价值叙事→卖点结构化）→ 信任（工艺→交付可见化→FAQ）→ 社证（评测/口碑/PK）→ 收官（早鸟兑现→提醒→承接）。

| 阶段 | 目的 | 素材 |
|------|------|------|
| D Day | 宣布起跑 | 理念视频 + KS 项目宣布/Update |
| D+1~2 | 价值叙事，解决"为什么买" | Hero 消费者价值叙事（TA 洞察→Problem→Solution→Benefit）+ 轻量证据图 1-3 张 |
| D+3~5 | 卖点结构化 + 拆条起步 | 3 卖点详情页 + 场景化 Demo（动作链路）+ 拆条 2-3 条 |
| D+6~10 | 高频补齐具体疑虑 | 拆条高频补充：每条只讲一个强点（握感/场景/细节） |
| D+11~14 | 工艺建立信任、放大二次传播 | 质感细节图集 + 社交扩散素材包（KS 内以证据+可读 Update 为主） |
| D+15~16 | 交付可见化（消除交付恐惧） | 产线照片/质检视频/包装物流图 + 里程碑 Update |
| D+17~18 | FAQ 消除最后障碍 | FAQ 图卡 3-6 张（疑问→结论→证据→下一步），来源 Discord+Reddit+邮件 |
| D+19~20 | 冲刺转化 + 感谢资产化 | 早鸟权益兑现 Update + 真实参与者感谢（不造假） |
| D+21 | 信息峰值（第二次理解+决策加速） | 海外完整详情页 + KOL 解禁素材包 + 国内 H5 同日发售 + 口碑汇总 |
| D+22 | 评测切片助推 | 评测合集（英文要点优先）+ 可验证口碑模块 |
| D+23 | 强化"我懂了/我相信了" | Q&A 汇总 Update + 直播 QA 切片（只留决策强相关） |
| D+25 | 第三方 PK 竞品 | PK 对比表/视频；**前置条件：证据充分、口径统一后才做** |
| D+26 | 社证最大化 | 内测用户真实图片/视频切片 + 口碑二次汇总 |
| D+27 | 收官提醒 | 收官 Update + 下一步价值卡片（交付时间线/支持承诺） |

**操作要点**：拆条原则=一条视频只讲一个强点；FAQ 必须来自真实社区问答；PK 对比不到证据充分不启动；D+21 峰值日国内外同步；收官不是终点——late pledge 与国内现货承接复用证据型素材。

## 提案标准结构 ⏳
1. 背景与目标（商业问题定义）
2. 人群洞察
3. 核心策略（六大师框架推导结论）
4. Big Idea 与创意概念
5. 传播节奏与渠道组合
6. 执行物料清单
7. 预算分配
8. KPI 与效果衡量

## 创意评估标准
- 每个方案须过三关：霍尔莫兹价值方程式（分子够大、分母够小）→ 高汀紫牛测试（值得被讨论）→ 奥格威标题测试（3 个标题里有 1 个能让人停下来）
- 另须通过 brand.md 红线检查（反同质化、坦诚原则、事实宣称有据）
- 内部评审流程与决策人：⏳ 待补充

## 效果衡量
- 帕特尔透镜：SEO 排名与长尾词流量、渠道 CTR/转化率、A/B 测试结果
- AM 可观测信号：售罄速度、社群讨论量、UGC 数量与质量、二级市场溢价/折价、独立站流量（baseline 月访 13 万）、众测招募完成度
- KPI 体系与复盘模板：⏳ 待补充

## 已知风险清单（方案中主动规避）
- 黄牛挤占真实用户 → 设计抽签/白名单/风控机制
- 工艺一致性（手工喷漆、石洗酸洗存在个体差异）→ 传播预期管理 + 售后预案前置
- 用户期望持续抬高（R2 翻车教训：负面会被社区放大）→ 不过度承诺，坦诚原则优先
- 小团队产能（2-10 人）→ 方案执行复杂度须与团队规模匹配，优先杠杆 UGC 与社区自组织
