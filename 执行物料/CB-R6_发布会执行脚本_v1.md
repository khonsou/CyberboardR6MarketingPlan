# CB R6 发布会执行脚本 v1

> 依据：《CB-R6-发布故事线》三幕 · 【32】《发布会》叙事弧 · 《CB-R6-产品故事》定稿 copy
> 状态：待团队 review · 占位项（日期/价格/发货承诺）以官宣口径为准
> 总时长：约 75 分钟（正片 60min + 收尾 15min）+ 会后直播 QA【33】

**发布会叙事弧（已定）**：钩子 Problem → 产品 Solution → 遭遇挑战（系统屏蔽）→ 尝试与突破（键盘固件自研 HID）→ 概念升华 Invisible AI IO → 演示（SP1 / SP2 / SP3 / 打字音 / HID 讲解 / 幻视 CB 首发）→ 言出法随收尾

**三条全场纪律**：
1. 所有演示用 T0 工程机**现场实拍、零渲染**，演示任务真实可复现（KS 合规与全线基调）
2. 口径红线：只说「说完即写入」不带数据（待试产复测）；「AM 第一把为 AI 时代造的键盘」，不做「全球首款」；收音绑定双击/按住动作，不得暗示常开监听；HID 仅键盘指令，不演示鼠标操作与通用 Agent
3. 每个演示环节**自带翻车预案**（录播备份同任务实拍视频，现场翻车 10 秒内切换）

## ACT 0 · 开场（0:00–0:05）

| 项 | 内容 |
|---|---|
| 画面 | 全场暗。大屏播放开场视频：编年史蒙太奇（1873 打字机 → 1964 鼠标 → 触屏 → 2026 对话），收在裸问题黑底白字 |
| 音乐 | 低频 drone 渐起，打字机声 → 电流声 → 骤静 |
| 大屏定格 | **「AI 已经可以聆听你。但为什么，今天的键盘还不行？」** |
| CUE | 视频结束，全场静 2 秒 → 一束冷光打在舞台中央桌面上——只有一把键盘。主讲人（楠总）从暗处上台，不说话，走到桌边 |

## ACT 1 · 钩子 Problem（0:05–0:12）

| 项 | 内容 |
|---|---|
| 口播（定稿原文） | 「AI 已经可以聆听你。但为什么，今天的键盘，还不行？」 |
| 口播 | 「你以为你在思考，其实你在搬运——把想法一个字一个字搬进电脑。这是这个时代最隐蔽的体力劳动。」「你以 1873 年的速度输入，和 2026 年的 AI 对话？」「思考是你的工作，搬运上下文不是。」（搬运三句，每句间留停顿） |
| 大屏 | 三句 copy 逐句浮现，无其他视觉干扰 |
| 口播 | 「你的想法以说话的速度奔涌，却被手指逐一截流。一段十分钟的完整思考，被压缩成二十分钟的敲击。桌面上的麦克风要吃下机械键盘的敲击声，耳机要一直戴在头上——设备越堆越多，只是为了和 AI 好好说一句话。」 |
| CUE | 灯光渐暗，大屏黑场 2 秒——制造 Pivot 前的停顿 |

## ACT 2 · Pivot 与 Reveal（0:12–0:18）

| 项 | 内容 |
|---|---|
| 口播（Pivot，定稿原文） | 「因为到今天为止，还没有一把键盘，为 AI 时代而生。」 |
| 大屏 | Pivot 句停顿 3 秒后，200 颗 LED 在黑暗中逐一点亮（舞台实拍 R6 灯光联动大屏），产品从暗场浮现 |
| 口播（Solution，定稿原文） | 「CYBERBOARD R6。第一把学会聆听的键盘。」 |
| 大屏 | 产品英雄镜头 + 「The first keyboard that listens.」 |
| 口播（八年之约，国内场限定） | 「2018 年，罗老师在鸟巢许下言出法随的愿。八年后，我们做出来了。」 |
| 大屏 | 2018 TNT 发布会公开画面 recall（仅用公知素材，致敬口吻，不消费失败）→ 切回现场 |
| 红线 | 致敬而非嘲讽；海外直播流此段掐掉，以编年史回填 |

## ACT 3 · Solution 第一层：先立住键盘（0:18–0:26）

> 叙事任务：对老圈层给定心丸——它首先是一把完全体 CYBERBOARD 旗舰。

| 项 | 内容 |
|---|---|
| 口播 | 「在谈 AI 之前，先谈键盘。200 颗 LED 矩阵、6063 CNC 铝合金、三段式 Leaf Spring、POM 定位板多层声学、冰银轴 Pro V3。」 |
| 画面 | 质感细节实拍穿插：CNC 边缘、阳极表面、LED 矩阵点亮 Monogram 像素 |
| 口播 | 「打字设备，桌面身份，AI IO——第一次，在一把键盘上三合一。」 |
| 演示 CUE | 现场打字音试听（**此环节固定保留**，见 ACT 8），此处只埋一句：「声音留到后面，老传统。」 |

## ACT 4 · 遭遇挑战：系统屏蔽（0:26–0:32）

> 叙事任务：讲清楚这件事为什么难——软件方案的天花板。

| 项 | 内容 |
|---|---|
| 口播 | 「我们一开始也以为，做一个 App 就够了。但你很快会撞上墙：操作系统不信任任何软件——它不信任你模拟出来的键盘。」 |
| 画面 | 大屏演示动画：软件模拟输入 → 被系统/应用屏蔽、焦点丢失、权限弹窗层层拦截 |
| 口播 | 「AI 软件公司做不到这里。不是不想，是不能——他们没有硬件。」 |

## ACT 5 · 突破：自研 HID 闭环（0:32–0:40）

> 叙事任务：发布会技术高光。讲清 App → R6 → 真实 HID 的链路。

| 项 | 内容 |
|---|---|
| 大屏 | 链路图逐步点亮：**按住说话 → App 识别意图 → R6 发出真实 HID 指令 → 电脑执行** |
| 口播 | 「所以我们把意图执行做进了键盘固件。R6 发出的不是模拟信号，是一个真实键盘的 HID Report——对电脑来说，就是你的手在敲。」 |
| 口播（边界口径，原话级） | 「也要说清楚边界：HID 只支持键盘按键和组合键，不支持鼠标。它不是通用 Agent。但在边界之内——言出法随。」 |
| 演示 CUE | **HID 技术讲解演示**：大屏分屏，左侧按键可视化，右侧电脑实时响应，证明「真实 HID」而非虚拟键盘 |

## ACT 6 · SP1 语音输入演示（0:40–0:46）

| 项 | 内容 |
|---|---|
| 演示 | 现场真实任务：双击 AI 键 → 浮窗实时转写 → 口述一段长需求 → 说完即写入任意输入框 |
| 口播 | 「边说边看，说完即写入。十分钟的完整思考，不再被压缩成二十分钟的敲击。」 |
| 红线 | 全程不说「1 秒」；如有观众问速度，口径「试产复测中，数据以复测公告为准」 |
| 翻车预案 | 现场网络/转写异常 → 切同任务录播实拍（大屏标注「工程机实录」） |

## ACT 7 · SP2 语音执行演示（0:46–0:52）

| 项 | 内容 |
|---|---|
| 演示 | 按住 AI 键说话：「帮我搜一下 XX，打开昨天的文档」→ 松开 → 电脑执行。任务限定在已确认能力（网页搜索 / 打开网站 / 预设指令 / 自定义脚本） |
| 口播 | 「Press. Speak. Done.——你按住，它倾听。你松开，它执行。」 |
| 加分项 | 现场让观众出题（预设白名单内任务），增强「真实可复现」说服力 |
| 红线 | 不出白名单；不接「帮我点一下那个按钮」类鼠标需求——正好顺势重申 HID 边界 |

## ACT 8 · SP3 降噪实测 + 打字音（0:52–0:58）

| 项 | 内容 |
|---|---|
| 演示 | 分屏波形图：左声道现场激烈敲击冰银轴，右声道同步人声转写——敲击声里只取人声 |
| 口播 | 「AI 阵列麦加音频 DSP，为机械键盘的敲击环境而生。你边打字，它边听得清你。」 |
| 红线 | 禁用「完全消除键盘声」，口径「只取你的声音」 |
| 打字音固定环节 | 灯光收暗，大屏只留声波纹。现场打字 30 秒纯享——AM 发布会传统，冰银轴 Pro V3 打字音 |
| 口播 | 「这一段没有台词。听就好。」 |

## ACT 9 · 桌面减法与心流（0:58–1:03）

| 项 | 内容 |
|---|---|
| 画面 | 桌面实拍：麦克风、音箱、耳机三件逐一贴上「已退休」标签收走，桌面只剩 R6 与一杯茶 |
| 口播（定稿原文） | 「你为一张干净的桌面做过那么多减法：无线化、藏线、精简设备——但麦克风、音箱、耳机，始终是多出来的那几件。R6 是桌面上的最后一件设备，因为它其实是一次减法：它们三个，退休了。」 |
| 口播 | 「你说，它听。你说完，它已经在屏幕上。你的注意力第一次完整地属于思考本身——心流。」 |

## ACT 10 · 概念升华：Invisible AI IO（1:03–1:08）

| 项 | 内容 |
|---|---|
| 大屏 | 编年史收口：1873 → 1964 → 触屏 → 2026，键盘的第三次觉醒 |
| 口播 | 「每个计算时代都有定义它的输入设备。AI 的原生交互是对话——交互已经换代，设备还没有。今天，设备追上来了。」 |
| 大屏 | **Invisible AI IO**（全称部署待 §6 专项会议结论，未决前只用此 Key Message 版本） |
| 口播（Realm，定稿原文） | 「言出，法随。——你说的，就是它办的。」*Say it. So it is.* |
