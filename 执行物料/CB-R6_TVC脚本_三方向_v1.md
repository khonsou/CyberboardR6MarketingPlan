## 一、功能方向 TVC 《三句话的事》

| 项目 | 内容 |
|---|---|
| 时长 / 比例 | 60s 完整版（可拆 3×15s 拆条），16:9 主版 + 9:16 裁切 |
| 投放位置 | KS 详情页功能区块、YouTube/IG 投放、【14】功能篇同源素材 |
| Key Message | 边说边看，说完即写入 / 按住说话，松开执行 / 边打字，边被听见 |
| 叙事任务 | 不讲理念，只演功能。三个真实任务，一镜一个卖点，全部实拍可复现 |

### 分镜脚本

| 镜号 | 时长 | 画面 | 声音 / 音乐 | 字幕 / VO |
|---|---|---|---|---|
| F0 | 3s | 黑场。一只手指悬在 CYBERBOARD R6 的 AI 键上方，LED 矩阵待机呼吸。 | 环境底噪，一声极轻的机械轴预压声 | 字幕：*三个演示，没有一句解说。* |
| F1 | 8s | **SP1 · 输入**：桌面实拍。用户双击 AI 键，屏幕浮窗实时转写，语速自然地说完一段长需求；松开，文字完整写入邮件输入框。 | 人声（真实收音）、轻微的键盘环境声、转写入框的一声轻响 | 字幕：**边说边看，说完即写入。** |
| F2 | 6s | 切特写：浮窗里文字逐字出现的瞬间；手指没有碰过键盘字母区。 | 音乐起：极简电子脉冲，一拍一进 | VO（低、平）：*Talk, not type.* |
| F3 | 10s | **SP2 · 执行**：同一桌面。用户按住 AI 键：「帮我查一下下周旧金山的天气，顺便打开昨天的文档。」松开——浏览器搜索完成、文档被打开。全程无鼠标操作。 | 人声、按键一声、页面切换的环境音 | 字幕：**按住说话，松开执行。**<br>小字：App 识别意图 → R6 发出真实 HID 指令 → 电脑执行 |
| F4 | 4s | 特写：AI 键按下的微距，键程、回弹、指示灯亮起的瞬间。 | 轴体声（冰银轴 Pro V3，打字音质感） | — |
| F5 | 10s | **SP3 · 降噪**：分屏。左：波形图里机械键盘激烈敲击；右：同一时刻的人声被干净取出。用户边打字边说话，转写不受干扰。 | 左声道敲击声放大 → 右声道人声清晰 | 字幕：**边打字，边被听见。**<br>小字：AI 阵列麦 + 音频 DSP，为机械键盘的敲击环境而生 |
| F6 | 8s | 拉回全景：干净桌面，只有一把 R6。麦克风、音箱、耳机的空位隐约可见（已收走）。 | 音乐渐弱，留白一拍 | VO：*One keyboard. Nothing else on the desk.* |
| F7 | 6s | 产品定格：R6 斜 45° 英雄角度，LED 矩阵亮起 Monogram 像素图案。 | 一声干净的收尾音 | 字幕：**CYBERBOARD R6 · 第一把学会聆听的键盘** |
| F8 | 5s | 尾卡：黑底，三行卖点依次亮起 → Logo + KS 上线信息。 | 静音 | 字幕：*The first keyboard that listens.*<br>小字：工程机实拍 · 演示任务真实可复现 |

### 功能片红线自查

- [x] SP2 演示任务限定在已确认能力（搜索 / 开网站 / 预设指令），无鼠标操作画面
- [x] SP3 用「在敲击声里只取人声」口径，禁用「完全消除键盘声」

- [x] 收音动作均有双击/按住画面，无常开监听暗示

## 二、品牌方向 TVC 《1873 → 2026》

| 项目 | 内容 |
|---|---|
| 时长 / 比例 | 90s，16:9 主版 + 9:16 裁切 |
| 投放位置 | D Day 品牌发布、【07】八年之约同日的话题扩散、发布会开场备选 |
| Key Message | 因为到今天为止，还没有一把键盘，为 AI 时代而生。→ 第一把学会聆听的键盘 |
| 叙事任务 | 把产品发布升维为交互编年史：键盘的第三次觉醒。回答「为什么是现在、为什么是 AM」 |

### 分镜脚本

| 镜号 | 时长 | 画面 | 声音 / 音乐 | 字幕 / VO |
|---|---|---|---|---|
| B0 | 6s | 黑场中一束冷光打出老式打字机字锤的剪影，字锤敲击，纸面出现字母。 | 打字机机械声，空旷混响 | 字幕：**1873** |
| B1 | 8s | 快切蒙太奇：打字机配列沿用至今的各种键盘特写（图书馆、办公室、网吧、深夜书桌），配列 150 年未变。 | 敲击声层层叠加，渐成节奏 | VO：*我们用它写信、写代码、写一切。* |
| B2 | 6s | 1964：鼠标原型（木质外壳）的档案感画面 → 现代鼠标在桌面滑动。 | 一声「咔哒」接电流声 | 字幕：**1964** |
| B3 | 6s | 移动时代：无数块触摸屏亮起，手指翻飞。 | 节奏加快，环境人声嗡鸣 | 字幕：**触屏时代** |
| B4 | 10s | 2026：一个人对着空气说话，AI 的回应在屏幕上奔涌——但他的手仍悬在键盘上，一个字一个字地敲。动作与思考速度的反差被放慢。 | 音乐骤停，只剩敲击声，越来越刺耳 | VO：**「AI 已经可以聆听你。但为什么，今天的键盘还不行？」** |
| B5 | 6s | 黑场。停顿两拍。 | 全静 | 字幕（逐行打出）：**因为到今天为止，还没有一把键盘，为 AI 时代而生。** |
| B6 | 12s | 冷光亮起：CYBERBOARD R6 从黑暗中浮现，200 颗 LED 渐次点亮如矩阵苏醒；CNC 铝合金边缘扫过一道青冷光。 | 低频脉冲起，赛博侘寂氛围铺底 | VO：**「CYBERBOARD R6。第一把学会聆听的键盘。」** |
| B7 | 12s | 快切使用场景：按住说话 → 松开执行 → 文字入框 → 桌面干净无一多余设备。动作安静、克制，像茶道「一手是一手」。 | 环境音收得很轻，只剩必要之声 | 字幕：**打字设备 · 桌面身份 · AI IO，第一次三合一** |
| B8 | 8s | （国内版限定）档案感闪回：2018 鸟巢发布会远景剪影 → 切回今天，楠总实拍镜头一句话。 | 旧现场声一闪而过 | VO：**「2018 年，罗老师在鸟巢许下言出法随的愿。八年后，我们做出来了。」**（海外版此镜删除，时长回填 B7） |
| B9 | 8s | 群像：不同的人对着自己的 R6 说话——程序员、设计师、写作者。每个人都只动嘴，屏幕在干活。 | 人声器乐化，汇成一句 | 合唱式 VO：**言出，法随。** |
| B10 | 8s | 尾卡：R6 英雄定格 → 黑底白字。 | 一声轴体声收尾 | 字幕：**AM 第一把为 AI 时代造的键盘。**<br>*The first CYBERBOARD built for the AI era.* |

## 三、Invisible AI TVC 《和 Agent 一起进入心流》

| 项目 | 内容 |
|---|---|
| 时长 / 比例 | 75s，16:9 主版 |
| 投放位置 | D Day 核心物料【06】理念视频，KS LP 首屏视频位 |
| Key Message | Invisible AI IO Coming |
| 叙事任务 | 官方定调之作：断流 → 接通 → 心流。不卖功能，卖「你和 Agent 第一次在同一个节奏里」的境界 |
| 视觉语言 | 赛博侘寂：科技感由材质与光承担（LED 矩阵、CNC、冷光），人性由节奏与留白承担（茶道式专注、侘寂式只留必要之物）；冷调留白，不触发 VI 负面清单 |

### 分镜脚本

**第一乐章 · 断流（0:00–0:22）**——心流被打断的元凶是「翻译/搬运」

| 镜号 | 时长 | 画面 | 声音 / 音乐 | 字幕 / VO |
|---|---|---|---|---|
| I1 | 8s | 深夜桌面。用户进入心流：打字、思考、屏幕内容飞速生长。画面一气呵成，镜头缓慢环绕。 | 长线条氛围音（drone），打字声融入节奏 | — |
| I2 | 7s | 用户突然停下——想到一个复杂需求，要「翻译」给 AI：切窗口、组织措辞、逐字敲入。画面节奏被打断，剪辑变得琐碎。 | drone 出现裂缝般的杂音 | 字幕：**你以为你在思考，其实你在搬运。** |
| I3 | 7s | 俯拍：双手在键盘上逐字搬运想法，屏幕那头的 AI 在等待。时间感被拉长、拖慢。 | 敲击声被放大成单调劳动声 | 字幕：**这是这个时代最隐蔽的体力劳动。** |

**第二乐章 · 接通（0:22–0:45)**——你说，它听；你松开，它执行

| 镜号 | 时长 | 画面 | 声音 / 音乐 | 字幕 / VO |
|---|---|---|---|---|
| I4 | 6s | 全黑。只有 AI 键的一颗灯亮起，像黑暗中唯一的应答。 | 全静一拍，然后一声极轻的按键声 | — |
| I5 | 8s | 微距：手指按住 AI 键。用户开始说话——不再组织措辞，像对同事说话一样自然。 | 人声真实、放松 | VO：**你的手本来就在键盘上，所以让键盘听见你。** |
| I6 | 9s | 松开手指的瞬间：意图被识别，HID 指令发出，屏幕开始自己干活。用户的手已经离开键盘，端起茶杯。 | 一声「通」的音色设计（接通感） | 字幕：**你说，它听。你松开，它执行。** |

**第三乐章 · 心流（0:45–1:15)**——你和 Agent 第一次在同一个节奏里

| 镜号 | 时长 | 画面 | 声音 / 音乐 | 字幕 / VO |
|---|---|---|---|---|
| I7 | 10s | 长镜头：用户靠在椅背上口述，屏幕内容随之生长；人和 AI 的节奏完全同步，像合奏。桌面干净——没有麦克风、音箱、耳机。 | 音乐第一次完整展开，安静而开阔 | — |
| I8 | 8s | 侘寂式空镜：桌面只有 R6、一杯茶、一束冷光。时间感消失。 | 音乐渐隐，留白 | VO：**心流。** |
| I9 | 8s | R6 英雄定格，LED 矩阵暗下，只剩 AI 键一点青光。 | 一声轴体声，归于寂静 | 字幕：**CYBERBOARD R6 · Invisible AI IO** |
| I10 | 6s | 尾卡。 | 静音 | 字幕：**言出，法随。——和 Agent 一起进入心流。**<br>*Say it. So it is.*<br>小字：*Invisible AI IO · Coming* |

### 理念片红线自查
