## 序幕 · 提问（KS LP 上线前，悬念期）

叙事任务：制造认知缺口——"对哦，为什么？"

keymessage：「AI 已经可以聆听你。但为什么，今天的键盘还不行？」/ *AI is listening to you. So why isn't your keyboard?*

节拍 1｜裸问题投放：「AI 已经可以聆听你。但为什么，今天的键盘还不行？」——匿名但可辨认：无品牌名/logo，画面为 CYBERBOARD 剪影与 LED 矩阵；懂的人一眼认出（圈层暗号），不懂的人被问题钩住。这句问句的力量在于：它成立得无可辩驳，却从未被问过。

节拍 2｜消失视频：一条视频，一天释放——高级桌面场景渐次消失：麦克风不见了、音箱不见了、耳机不见了……最后只剩一把键盘的轮廓。

节拍 3｜悬念峰顶：No Typing 实拍——一把 CYBERBOARD，键帽全部拔出，只剩一颗发光的 AI 键。*The keyboard built for no typing.*（T0 工程机实拍、零合成）

节拍 4｜痛点加深（QA 追加，待团队 review）：「隐蔽的体力劳动」三句——「你以为你在思考，其实你在搬运——把想法一个字一个字搬进电脑。这是这个时代最隐蔽的体力劳动。」「你以 1873 年的速度输入，和 2026 年的 AI 对话？」「思考是你的工作，搬运上下文不是」——为 Problem 问句提供血肉。

观众心理路径：这是什么？→ 为什么东西在消失？→ 为什么只剩一颗键？→ 那颗键是什么？→ AM 要发什么？

可信性设计：全序幕零功能宣称——只有问题和画面，不积累任何"证据债"。悬念期最大的翻车风险是过度承诺，我们从结构上免疫它。No Typing 为实拍，无合成误导风险。

织入：Godin（紫牛 = 没有键的键盘，天然值得讨论）

## 一幕 · 揭示（D Day：KS LP 上线 / 海外完整详情页发布）

叙事任务：把认知缺口接到产品事实——"Wait… the keyboard?"

keymessage：「Invisible AI IO Coming」

节拍 1｜重点证据视频：recall 罗老师当年失败的 TNT 演示，CB R6 配合 Agent 完成了。 李楠「2018 年，罗老师在鸟巢许下言出法随的愿。八年后，我们做出来了。X 月 X 日见。」

节拍 2｜Reveal 三句：「因为到今天为止，还没有一把键盘，为 AI 时代而生。」→「CYBERBOARD R6。第一把学会聆听的键盘。」英文：*Because no keyboard has ever been built for the AI era. → The first keyboard that listens.*

节拍 3｜理念视频 **Invisible AI IO**：《和 Agent 一起进入心流》：断流（"翻译/搬运"是心流被打断的元凶）→ 接通（你说，它听；你松开，它执行）→ 心流（你和 Agent 第一次在同一个节奏里）。视觉语言：赛博侘寂（见文末）。

节拍 4｜编年史叙事：1873 打字机配列 → 1964 鼠标 → 移动时代触屏 → 2026 对话。键盘的第三次觉醒：打字设备、桌面身份、AI IO，第一次三合一。

节拍 5｜实拍演示：工程机实录与 Reveal 同日放出；演示任务真实可复现

观众心理路径：原来是键盘！→ 它怎么做到的？→ 1873 到 2026，还真没人做过 → 我想看它真的工作。

可信性设计：本幕所有宣称限定在 FABE 已确认能力内；实拍证据与宣称同日上架；禁用未核实的"全球首款 AI Keyboard"，只用"AM 第一把为 AI 时代造的键盘"。

织入：Naval（编年史回答"为什么是现在"）+ Handley（以"你"为中心的共情）+ Hormozi（心流境界 = 梦想结果）

## 二幕 · 证明（KS 周期中段）

叙事任务：把"好听的故事"兑换成"被验证的事实"——没有一条物料是"再讲一遍故事"。

keymessage：「CYBERBOARD R6 - Voice First Invisible AI IO」

节拍 1｜设计篇，产品桌面美图和视频。

节拍 2｜功能篇，产品实际操作演示视频，靠说话让 Kimiwork 干活，然后切换浏览器刷 b 站。

节拍 3｜心流篇，产品实际操作视频，躺着操作键盘的无感体验。

节拍 4｜工艺质感 + 交付可见化：细节图集、产线/质检/包装物流、里程碑 Update。

节拍 5｜FAQ 图卡：疑问 → 结论 → 证据 → 下一步；来源 = Discord / Reddit / 邮件真实问答。

节拍 6｜坦诚三件套：公开试产复测计划（1 秒写入 / 成功率 / 蓝牙）；订阅制显著披露 + 创始档长期权益；能力边界主动明示（"不是通用 Agent""HID 不支持鼠标"）。

节拍 7｜众测 / 内测：真实用户替品牌说话，UGC 飞轮接管叙事。

观众心理路径：它真的行吗？→ 实测也这么说 → 官方连边界都自己讲了 → 我信了。

可信性设计：本幕即可信性本身——证据全部来自实拍、第三方与真实问答。节奏参照 KS 30 天模板（skill 打法 #7），具体排期待流程文档。

织入：Ogilvy（基于事实的说服）+ AM 坦诚原则 + 社区已验证打法（众测 → UGC 飞轮）

## 三幕 · Launch 和 meaning（信息峰值 → 国内发布 → 发布会 → 收官）

叙事任务：从产品发布升维为时代叙事，让社区成为共同作者。

keymessage：「言出法随——和 Agent 一起进入心流。」/ *Say it. So it is.*

节拍 1｜内测第三方口碑汇总混剪：KOL 解禁素材包 + 评测合集 + 口碑汇总，国内外同步——"我懂了 / 我相信了"收口。

节拍 2｜发布预热倒计时：倒3 播放歌曲的时候用语音回复微信 倒2 躺着只动嘴让 coding agent 改一个鼠标网页驱动的 bug（AM 的程序员有了 CB R6 躺着工作了）倒 1 AI 时代的桌面极简美学视频

节拍 3｜发布会：钩子：Problem，产品：solution，遭遇挑战：系统屏蔽，尝试和突破：键盘固件自研支持 HID ，概念升华：Invisible AI IO，美图和具体场景演示：SP1 语音输入演示（边说边看，说完即写入）、SP2 语音执行演示（按住说话，松开执行）、SP3 阵列麦打字降噪实测、打字音固定环节（冰银轴 Pro V3）、HID 技术重点讲解（App → R6 → 真实 HID 闭环）、幻视 CB 独立素材首发；以上演示事后切片，回流传播追加流量。

节拍4 ｜发布会后直播 QA ，预定利好，发货承诺

观众心理路径：大家都在说 → 原来这是一件大事 → 八年了，真有人把它做出来了 → 我也想对它说点什么。

可信性设计：口碑与评测全部可验证、可回溯；公共叙事由媒体与社区自发转述，品牌不自我吹嘘。

织入：Godin 部落（共庆而非投放）+ Patel（评测切片、SEO 收口；话题借势窗口：9 月 AGNTCon / MCPCon / Voice Agents Forum，10 月 GTC Berlin / GitHub Universe）

## 视觉概念：赛博侘寂（Cyber Wabi-sabi）

科技与人性内省的反差美学——最前沿的 AI 能力，以最安静的方式存在。科技感由材质与光承担（LED 矩阵、CNC 金属、冷光），人性由节奏与留白承担（茶道"一手是一手"的仪式专注、禅宗"当下"的时间感消失、侘寂"只留必要之物"）。冷调留白，不触发 VI 负面清单；如需暖镜头，按 Protocol v4.0 在 Block A 显式标注偏离。执行遵循 VI Protocol（Block A/B/C 工单、Monogram 物理存在）。
