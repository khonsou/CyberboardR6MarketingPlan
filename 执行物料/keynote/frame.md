# CB R6 Keynote · frame.md（设计系统 · 镜头版）

> 用途：发布会 H5 deck 的单一设计来源。所有屏的画面只允许消费这里的 token，禁止就地发明颜色/字号/时长。
> 版本：v3（2026-10-12，暖调深色；v2 暖纸浅色被否，v1 冷青被否——锁定原则：**深色底、零蓝调**）
> 风格参考：Anthropic slate 暖墨 + 陶土点缀的深色反相；serif 承担人性，sans 承担宣告
> ⚠️ 偏离声明：本 deck 色彩按项目决策独立于 AM VI Protocol v4.0，仅用于发布会屏幕

## 色彩 Token 语义说明

Token 按**角色**命名而非按颜色命名：`--ink` 永远指「主文案色」——浅色主题里它是墨（#141413），深色主题里它是纸（#F0EEE6）。换主题只改 :root，不动任何屏的代码。

## 画布 Stage

| 项 | 值 | 说明 |
|---|---|---|
| 分辨率 | 1920 × 1080 | 固定舞台，整体等比缩放适配屏幕 |
| 安全边距 | 120px | 任何文字不进入边距外 |
| 背景 | `--bg: #171512` | 暖调深炭，带棕意不带蓝意，全场唯一底色 |
| 气氛光 | radial 陶土辉光，透明度 ≤ 0.12 | 只允许出现在 Reveal 类屏 |

## 色彩 Color（v3 暖深）

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | #F0EEE6 | 主文案：暖米白（深色主题下的"墨"） |
| `--clay` | #D97757 | 唯一强调色：Solution 句、LED 点亮态（深底上用亮一档的 Clay） |
| `--dim` | #B0AEA5 | 次要文案 / 英文对照 |
| `--faint` | #6E6A60 | 装饰文字 / 弱化信息 |
| `--line` | #2E2B25 | 分隔线、点阵熄灭态 |

**禁色**：任何蓝、青、紫及其渐变——这是 v1 被否的原因，写进系统防止回潮。

## 字体 Typography（双轨制：sans 宣告 / serif 人性）

| 角色 | 规格 |
|---|---|
| Hero 中文 | PingFang SC Semibold 96px / 1.4 |
| Pivot 中文 | PingFang SC Medium 56px / 1.8 |
| 英文对照 | **Georgia Italic 28px**，--dim（serif = 编辑感、人性） |
| 品牌字标 | Helvetica Neue 72px，letter-spacing .28em（sans = 宣告） |

## 节奏 Motion

| 项 | 值 | 说明 |
|---|---|---|
| 分步浮现 | opacity 0→1 + translateY 24px→0，600ms，cubic-bezier(.22,.61,.36,1) | 每步一个 fragment |
| 屏间转场 | fade-through-black 500ms | 先暗后亮 |
| LED 唤醒 | 200 颗点阵，随机错峰点亮为陶土色，总时长 ≤ 1.8s | 仅 Reveal 屏使用一次 |
| 禁 | 弹跳、弹性回冲、蓝紫渐变、阴影堆叠、玻璃拟态 | — |

## 红线（视觉侧）

- 深色暖底 + 大量留白；无人脸素材、无可爱元素
- 单屏最多一个 Hero 信息；英文永远弱于中文一级
- 强调色一屏只出现一次（Solution 句或 LED，不叠加）
- 「AM 第一把」口径，无「全球首款」字样
